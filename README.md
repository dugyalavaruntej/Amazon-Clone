# 🛒 Amazon Clone

This is a fully responsive front-end clone of Amazon's homepage, built with HTML, CSS, and FontAwesome. The project mimics key features of Amazon's e-commerce platform, including a navbar, search bar, categories, and a footer.

## ✨ Features

- **Responsive Navbar**: 
  - Search bar with categories dropdown.
  - Account options and cart.
  - Location-based delivery information.
- **Hero Section**: 
  - A promotional banner with a call-to-action to visit Amazon India.
- **Product Categories**: 
  - Clean grid layout showcasing products like Clothes, Electronics, Beauty, and more.
- **Interactive Footer**: 
  - Quick links to Amazon’s resources (Careers, Investor Relations, Blog, etc.).
  
## 🚀 Technologies Used

- **HTML5**: For creating the structure of the website.
- **CSS3**: For styling and making the website responsive.
- **FontAwesome**: For icons and UI elements.

1. **Clone the repository**:
   ```bash

   ```

2. **Navigate into the project directory**:
   ```bash
   cd amazon-clone
   ```

3. **Open `index.html`** in your preferred browser to view the project:
   ```bash
   open index.html
   ```
